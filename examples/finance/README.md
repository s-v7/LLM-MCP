# Finance MCP Example

## Purpose

This module demonstrates how MCP can expose financial-system capabilities through safe, structured tools.

The goal is educational: simulate common finance workflows without using real sensitive data.

## Possible tools

- `list_accounts`
- `list_transactions`
- `search_transactions`
- `summarize_cashflow`
- `get_invoice_status`
- `detect_duplicate_payments`

## Example questions

```text
Show transactions from last month.
Summarize cash flow by category.
Find invoices that are overdue.
Detect possible duplicate payments.
Show expenses grouped by account.
Data safety
```

This example must use synthetic data only.

Do not store real bank data, real invoices, CPF/CNPJ, card numbers or production credentials in this repository.
