# Project Vision

LLM-MCP Lab is a practical repository for learning and demonstrating MCP-based AI application architecture.

## Main goal

Build a portfolio-ready MCP laboratory that shows how LLM clients can interact with tools, resources and data systems through a clear protocol layer.

## Scope

This project should include:

- small MCP examples;
- reusable server patterns;
- reusable client patterns;
- documentation-first implementation;
- automated tests;
- synthetic data only.

## Out of scope

This project should not include:

- real credentials;
- real financial data;
- real personal data;
- production secrets;
- unstable large refactors without tests.

## Implementation strategy

1. Keep the current cars example working.
2. Document the architecture.
3. Add examples one at a time.
4. Add tests before or together with new features.
5. Refactor only in small commits.
