# Roadmap — LLM-MCP Lab

## Visão

Transformar o LLM-MCP em um laboratório prático de MCP, demonstrando servidores, clientes, tools, resources, prompts e integrações com LLMs.

## Fases

- ✅ v0.1 — SQLite Server
- ✅ v0.2 — Cars Example
- 🔜 v0.3 — PostgreSQL MCP Server
- 🔜 v0.4 — FastMCP
- 🔜 v0.5 — Claude Desktop Integration
- 🔜 v0.6 — OpenAI Integration
- 🔜 v0.7 — Anthropic Integration
- 🔜 v0.8 — RAG Server
- 🔜 v0.9 — Multi Server
- 🔜 v1.0 — AI Agent

## Objetivo de vitrine

Este projeto deve demonstrar:

- Python moderno
- Arquitetura cliente-servidor
- Protocolo MCP
- Integração com bancos relacionais
- Uso de tools, resources e prompts
- Testes automatizados
- Documentação técnica clara
- Evolução para agentes com LLMs
