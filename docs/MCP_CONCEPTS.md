# MCP Concepts

## Tool

A tool is an action exposed by an MCP server.

Examples:

- search cars
- list transactions
- read a PDF
- query a database

## Resource

A resource is data exposed by an MCP server.

Examples:

- a SQLite table
- a PDF file
- a JSON document
- a system report

## Prompt

A prompt is a reusable instruction template.

Examples:

- summarize search results
- explain SQL output
- classify a document
- generate a report
